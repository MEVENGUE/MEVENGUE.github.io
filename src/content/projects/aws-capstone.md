## Architecture

The AWS Academy capstone designs a highly available estate across availability zones. VPC segmentation, subnets, NAT Gateway and Security Groups define network boundaries; IAM roles and policies enforce least privilege.

EC2 Auto Scaling adapts compute capacity, while S3 and EBS address object and block storage requirements. Cost and operational automation are treated as architecture inputs rather than post-launch optimizations.
