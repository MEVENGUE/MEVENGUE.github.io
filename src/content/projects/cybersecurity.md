## The study

This ECAM EPMI project examines the 2022 CISA vulnerability catalogue and connects data analysis to practical security work: phishing email classification, Nmap network reconnaissance, packet analysis with Scapy and cryptographic implementations.

Qlik dashboards transform the dataset into decision-ready views, while Python experiments bridge analysis and automation.
