## Operational security

This SUPINFO project secures a critical Linux environment through SSH and sudoers controls, MFA, auditd logging, SELinux or AppArmor policies, and host firewalls.

Prometheus and Node Exporter support supervision. Encrypted, retained backups use rsync and Borg, while documented recovery and failover exercises ensure the plan is executable—not merely written.
